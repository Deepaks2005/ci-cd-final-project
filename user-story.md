# User Story Template

## User Story

As a [type of user],
I want [an action or feature],
so that [a benefit or value].

## Acceptance Criteria

- Given [the initial context], when [an action is performed], then [the expected result].
- Given [another context], when [an action is performed], then [the expected result].

## Example

As a customer,
I want to create an account,
so that I can access the application's features.

### Acceptance Criteria

- Given I am on the registration page, when I submit valid details, then my account is created.
- Given I submit invalid details, when I submit the form, then I see a clear error message.
